# Sincere Translation — verification tooling

This repository holds **code and automated tests only** for the Sincere Translation Old Testament project.

## Canonical content and current status

- The canonical manuscript, CHES source material, CVOT comparison source, source-span ledger and publishing checkpoints remain in a **private Google Drive project workspace**.
- This public repository is **not** a Bible text repository, authoritative manuscript, or a source for its publication.
- Last verified working reader at initialization: **v3.1**, covering 39 books, 929 chapters and 23,145 verses. Status: **DRAFT_REVIEW_REQUIRED**. These are technical coverage figures, not a claim of completed linguistic review.
- Nehemiah 7:68 is an unresolved CHES source-span exception.

## Security and editorial rules

Do not commit, attach to issues/PRs, print in CI logs, or upload as public Actions artifacts: original CHES/CVOT data, private manuscript/volume contents, complete private verse ledgers, source excerpts or access credentials.

The forthcoming checks validate code against **synthetic fixtures**. They do not certify the 23,145 source verses, actual CVOT typography, or final Hebrew grammar. Real-manuscript changes must be independently verified against private sources before a new reader edition can be approved.

Never modify unrelated projects or repositories.
